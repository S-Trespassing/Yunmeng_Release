# 雨 (Rain)

`Rain` 是一款面向在校生的教务辅助应用，聚合常用校园教务功能，并采用樱花风格视觉设计，强调“好看 + 好用”。

## 软件简介

`Rain` 提供课程、成绩、考试、培养方案等高频查询能力，减少频繁打开网页教务系统的操作成本。  
在工具属性之外，应用也针对界面做了二次元/樱花主题优化，保证信息可读性与使用体验。

## 主要功能

- 我的课表
- 空教室查询
- 考试安排
- 我的成绩
- GPA 计算器
- 成绩可视化
- 选课结果查询
- 培养方案查看
- 校历查看（支持双指缩放、拖动）
- 一键评教（支持策略选择与执行日志）
- 工具页（内置常用网站入口）

## 适用平台

- Android（最低版本 Android 8.0 / API 26）

## 软件特色

- 教务高频功能集中在一个应用中
- 首页卡片式导航，常用功能可快速触达
- 樱花主题 UI，兼顾风格化与可读性
- 多页面统一交互逻辑，学习成本低

## 使用说明

1. 打开应用并完成登录。
2. 在首页选择需要的功能卡片进入对应页面。
3. 按页面提示完成查询或操作（如空教室、成绩、评教等）。
4. 校历页面支持双指缩放与拖动查看细节。

## 重要说明

- 本软件仅用于学习与教务信息辅助查询。
- 一键评教功能请在遵守学校规定的前提下使用。
- 本仓库为**闭源项目**，仅用于软件发布与维护说明，不提供开源协作。
