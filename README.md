# \## ✨ 项目定位

# 

# > \*\*云梦\*\* 是一款围绕校园教务高频场景打造的综合型工具应用。  

# > 它不仅解决“查信息”这件事，还尽量把“提醒、整理、处理、直达”一起做好。

# 

# 和传统只做网页封装的教务工具不同，`云梦` 更强调三件事：

# 

# \- \*\*入口统一\*\*：把高频功能集中在一个首页里，减少在多个网页之间来回切换

# \- \*\*体验更顺手\*\*：樱花主题、统一交互、轻量动效和清晰的功能分层，让日常使用更舒服

# \- \*\*能力更完整\*\*：除了课表、成绩、考试，还覆盖公告、选课捡漏、论坛、公文处理、PDF 工具、音乐等延展能力

# 

# ---

# 

# \## 🌸 视觉与气质

# 

# \- 整体采用 \*\*樱花 / 粉白 / 轻二次元\*\* 的风格路线

# \- 首页、弹窗、输入框、卡片等组件统一使用 `Sakura` 视觉语言

# \- 支持花瓣动效、柔和配色和更轻盈的层次表现

# \- 在“好看”的同时，仍然优先保证信息密度与可读性

# 

# 一句话说，`云梦` 不是只把功能堆在一起，而是希望把校园工具做成 \*\*愿意每天打开的应用\*\*。

# \## 🚀 值得重点介绍的能力

# 

# \### 1. 首页不是“入口堆砌”，而是高频功能的重新组织

# 

# 首页直接放入以下核心入口：

# 

# \- 我的课表

# \- 空教室

# \- 空教室 2

# \- 我的成绩

# \- 考试安排

# \- 选课结果

# \- 培养方案

# \- 预选课查询

# \- 选课推荐

# \- 排名查询

# \- 校园论坛

# \- 校历

# 

# 工具页则进一步收纳：

# 

# \- 公文处理

# \- 扫描去水印

# \- 一键评教

# \- 官网公告

# \- 音乐

# \- 选课捡漏

# 

# 这样的组织方式更像一个 \*\*校园效率工作台\*\*，而不是若干孤立页面的集合。

# 

# \### 2. 不只是“能查”，还支持“持续盯”

# 

# `云梦` 的一大亮点是后台监控能力：

# 

# \- 新成绩出来时，可以更早收到提醒

# \- 官网公告出现更新时，不需要反复手动刷新

# \- 选课捡漏场景里，可以持续检查课程容量变化

# 

# 对用户来说，应用从“信息查询器”升级成了 \*\*变化提醒器\*\*。

# 

# \### 3. 教务之外，保留了真正有用的校园延展功能

# 

# 除了教务主线，`云梦` 还把一些使用频率很高、但通常分散在不同位置的能力整合到一起：

# 

# \- 校园论坛

# \- 官网公告

# \- 公文处理

# \- 扫描 PDF 去水印

# \- 音乐工具

# 

# 这让应用不只适合“查一次”，而是更适合长期留在手机里当作日常工具箱。
